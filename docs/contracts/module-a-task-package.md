Модуль загрузки делится на 2 принципиальных блока:
1. ДАнные для инициализации гидродинамической модели OPM Flow и ее настройки:
  1.1 ДАнные о свойствах флюида (PVT)
  1.2 Данные о начальном состоянии пласта (начальное пластовое давление)
  1.3 данные относительных фазовых проницаемостей
  1.4 данные траекторий скважин
  1.5 данные перфораций скважин
  1.6 история добычи, закачки, пластовых и забойных давлений
  1.7 принадлежность скважин к группе и слою (объекту инфраструктуры)
2. Данные для формирования прогнозных сценариев
  2.1 текущий технологический режим работы скважин ('wells')
  2.2 список ГТМ (GTM)
  2.3 даты проведения ГТМ - берутся в зависимости от того, по какой ветке сценария идём: если используется внешний график КРС, то на ГТМ применяются даты реализации из внешнего графика КРС; Если используется формирование графика, то используется цикл с использованием экономики, ограничения по бригадам и инфраструктуре; Если используется полученный из planner после ревизии, то используется график после ревизии
  2.4 собственно внешний график КРС

  Все данные увязаны между собой. Например, скважина должна называться одинаково в гидродинамической модели и в графике КРС и в техрежиме.
