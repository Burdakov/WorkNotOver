# Контракт Module E

## Модуль

`Module E: Инфраструктурные ограничения`

## Назначение

`Module E` валидирует сценарный профиль добычи на ограничения инфраструктуры.

## Входы

- `ProductionScenario`
- `InfrastructureObject[]`
- `InfrastructureConnection[]`

## Выходы

- `InfrastructureConstraintCheckResult`
- `InfrastructureViolation[]`
- object-level load summaries

## Зона ответственности

- учёт даты ввода объектов
- учёт ограничений линейных объектов
- учёт ограничений площадочных объектов
- агрегация нагрузки по объектам
- возврат формализованного ответа в optimizer

## Не входит

- построение графика КРС
- изменение сценария
- ручная коррекция графика
- UI-логика

## Зависимости

- получает инфраструктурные данные из `Module A`
- получает production profile из `Module B`
- отвечает `Module D`

## Контрактные правила

1. `Module E` валидирует сценарий, но не исправляет его.
2. Ответ должен быть пригоден для использования в optimizer.
3. Любое нарушение должно содержать дату, объект, метрику и величину превышения.
