# Контракт Module C

## Модуль

`Module C: Экономика`

## Назначение

`Module C` владеет расчётом экономики мероприятий и сценариев.

## Входы

- `ProductionScenario`
- `EconomicsConfig`
- при необходимости: нормализованные метаданные мероприятий

## Выходы

- `GtmEconomicsResult[]`
- `EconomicsResult`
- scenario-level KPI

## Зона ответственности

- расчёт экономики отдельных мероприятий
- расчёт экономики сценария
- формирование итоговых KPI
- учёт выручки и затрат, связанных с добычей газа
- пересчёт экономики после planner-driven recalculation

## Не входит

- физика добычи
- построение графика КРС
- инфраструктурная валидация
- редактирование planner schedule

## Зависимости

- получает production outputs из `Module B`
- отдаёт результаты в `Module D` и `Module G`

## Контрактные правила

1. `Module C` не должен сам пересчитывать `ProductionScenario`.
2. Экономика всегда привязана к `scenario_id`.
3. Газовая составляющая экономики рассчитывается на основании того же `ProductionScenario`, что и нефть/жидкость.
4. Ручная правка из planner попадает в `Module C` только через новый пересчитанный сценарий.
